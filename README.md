# Memory Gym

A free, offline-capable memory training app (PWA). No accounts, no subscription, no tracking.

**Trainers:** numbers, word lists (with your memory palace), card order, names & faces, Major System speed drill.
**Tools:** memory palace builder + route test, editable 00–99 Major System images, spaced-repetition flashcards, technique lessons, streaks, personal bests, backup/restore.

Progress is stored in the browser on each device (localStorage). Use **Stats → Backup** to move it between devices.

## Install on iPhone
Open the site in Safari → Share → Add to Home Screen.

## Deploy
Static files only; served by GitHub Pages from `main`. Bump `VERSION` in `sw.js` on each release so installed copies update.
